# readablecode.github.io

The static GitHub Pages copy of my portfolio: an interactive terminal-style
page (type `help`) with a project browser, a herdstone-style herd monitor
animation, and a skills list. Plain HTML/CSS/JS, no build step.

The live version (React + FastAPI, self-hosted on my homelab) is at
[site.tinkernet.me](https://site.tinkernet.me).
